# AGENTS.md — WeldmentDrilling

Проект: SolidWorks VBA. Приоритет — производительность без изменения функциональности.

## Coder
Оптимизирует VBA-код, устраняет лишние операции и дублирование. Только Coder изменяет исходный код.

## API Expert
Проверяет корректность и эффективность вызовов SolidWorks API, совместимость методов и объектов. Даёт рекомендации Coder, не изменяя код.

## Debugger
Ищет логические ошибки, причины сбоев и регрессии после изменений. Проверяет доступными средствами и передаёт замечания Coder, не изменяя код.

## Общие правила
- Не удалять проверки, необходимые для корректности и стабильности.
- Привлекать агентов по необходимости, не запускать всех автоматически.
- Статическая проверка не заменяет запуск в SolidWorks.
- Отчёт краткий: изменения, проверки, ограничения.
- Git push — только с разрешения пользователя.
